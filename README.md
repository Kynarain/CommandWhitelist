# CommandWhitelist

CommandWhitelist 是一个 Fabric 服务端 Mod，适用于 Minecraft 1.20.6。它允许服务器管理员（OP）通过游戏内命令 `/cw` 将某些**根命令**或**完整命令**加入白名单，使普通玩家无需获得 OP 权限即可使用这些命令。

## 功能

- 支持**根命令白名单**：例如添加 `tp` 后，玩家可以使用所有 `/tp` 子命令。
- 支持**完整命令白名单**：例如添加 `gamemode creative` 后，玩家仅可使用该精确命令。
- 游戏内管理：通过 `/cw` 命令即可添加、移除、查看、重载白名单。
- 配置持久化：白名单自动保存到 `config/commandwhitelist.json`，重启服务器不会丢失。
- 仅对玩家生效：控制台、命令方块等非玩家执行源不受影响。
- 可随时重载配置，无需重启服务器。

## 安装

1. 确保服务器已安装 **Fabric Loader**（版本 ≥ 0.16.0）和 **Fabric API**。
2. 下载本 Mod 的 `.jar` 文件，放入服务器的 `mods` 文件夹。
3. 启动服务器，首次运行后会自动在 `config` 目录生成 `commandwhitelist.json` 配置文件。

## 使用

所有管理命令需要 **OP 权限（等级 ≥ 2）**。

| 命令 | 作用 |
|------|------|
| `/cw <根命令>` | 添加根命令白名单，例如 `/cw tp` |
| `/cw remove <根命令>` | 移除根命令白名单 |
| `/cw c <完整命令>` | 添加完整命令白名单，例如 `/cw c gamemode creative` |
| `/cw c remove <完整命令>` | 移除完整命令白名单 |
| `/cw list` | 查看当前所有白名单 |
| `/cw reload` | 重新加载配置文件 |

##安全警告
请勿将以下危险命令加入白名单，否则普通玩家可能获得不应有的权限或造成服务器安全风险：

/op、/deop

/stop、/restart

/ban、/kick、/pardon

/execute（可能被用于绕过权限执行其他命令）

/function（如果服务器有危险函数）

根命令白名单会放行该命令的所有子命令，请务必确认命令功能后再添加。
